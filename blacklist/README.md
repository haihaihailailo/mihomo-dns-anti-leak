# Android 分应用代理黑名单（历史记录）

这些文件记录旧版 Clash Mi / Android 分应用代理的黑名单方案，仅用于历史核对和回退，不是当前默认名单。分应用白名单或黑名单由客户端管理；不要将这些旧文件直接导入覆盖正在使用的名单。

## 原则

- 黑名单中的应用完全绕过 Android VPN，直接使用系统网络。
- 只放确实需要绕过 VPN 的超级 App / 小程序入口，不要把所有国内 App 都加入黑名单。
- 修改黑名单后，需要停止并重新启动 VPN，再完全退出相关 App 重新测试。
- 不要把 Clash Mi 自身 `com.nebula.clashmi` 加入黑名单。
- 不要开启 Android 系统的“无 VPN 时阻止连接 / Block connections without VPN”，否则黑名单 App 可能无法联网。

## 历史默认黑名单

| 应用 | 包名 | 原因 |
|---|---|---|
| 微信 | `com.tencent.mm` | 小程序、H5、第三方商家页面属于混合入口，直接绕过 VPN 更稳定 |
| 支付宝 | `com.eg.android.AlipayGphone` | 小程序、H5、支付与第三方服务属于混合入口，直接绕过 VPN 更稳定 |

## 暂不默认加入

QQ、云闪付、银行、数字人民币、政务、钱包类 App 暂不默认加入。只有实际出现加载失败、定位异常、支付失败或风控问题时，再按设备单独加入。

## 当前配置配合

- 国内版：已进入 VPN、且被正确识别的微信和支付宝流量，由应用规则直接送往 DIRECT；不设国内服务或中国节点组。
- 国外版：对应流量送往 `国内服务`，默认 DIRECT，有回国需求和可用回国节点时再手动调整。
- 白名单之外或被黑名单排除的 App 完全绕过 VPN，仓库规则和策略组不能接管；是否让某个 App 进入 VPN 由设备使用者决定。
- Chrome、Android System WebView、雨见等混合入口继续按域名分流；外部浏览器、其他进程发出的请求不保证沿用原 App 的出口。
- 如需因兼容性临时调整名单，先备份客户端配置并做单机验证。本仓库不修改手机名单，也不要求恢复历史黑名单。
